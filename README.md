# Lenny's Data

A comprehensive archive of [Lenny's Podcast](https://www.lennyspodcast.com) transcripts and [Lenny's Newsletter](https://www.lennysnewsletter.com) posts, in AI-friendly markdown, to inspire you to build something with this unique dataset.

This repo is the full private archive for paid subscribers.

## What is included

- Full archive: **349 newsletter posts** and **289 podcast transcripts** in this private repo
- Paid subscribers can also download the full archive as a ZIP and connect to the MCP at [lennysdata.com](https://www.lennysdata.com)
- Newsletter posts published within the last 3 months are intentionally excluded from this archive.
- All files are plain markdown and easy to use with Claude Code, Cursor, and other AI tools
- `index.json` includes titles, dates, tags, and word counts, plus newsletter subtitles when available and podcast guests and descriptions.

## Repo layout

- `index.json`
- `newsletters/`
- `podcasts/`
- `LICENSE.md`

## Quick Start

1. Clone with `git clone https://github.com/LennysNewsletter/lennys-newsletterpodcastdata-all.git`.
2. If you prefer a ZIP instead of cloning, sign in at [https://www.lennysdata.com](https://www.lennysdata.com) and download it there.
3. If you want MCP access, see [https://www.lennysdata.com/docs/mcp](https://www.lennysdata.com/docs/mcp).
